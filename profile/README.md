**エレキベアのデジタルラボの GitHub へようこそ！**

YouTube チャンネルで扱ったサンプルとツールのソースコードを置いています。\
動かせるものは [Elekibear Lab](https://lab.elekibear.com/) からブラウザで触れます。

- **講座のサンプル** — 順番に学べる講座で作るコード。日本語版と英語版でリポジトリが分かれています（`-ja` / `-en`）
- **作ってみたもの** — ゲームやツールを作ってみる動画のアプリ
- **ツール** — 動画づくりに使っているツール
