**Welcome to the Elekibear Digital Lab GitHub!**

Here you'll find the source code for the samples and tools from our YouTube channel.\

- **Course samples** — code from our step-by-step courses. Japanese and English versions live in separate repositories (`-ja` / `-en`)
- **Projects** — apps from videos where we build games and tools
- **Tools** — tools we use to make our videos
